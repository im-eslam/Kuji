Components are built bottom-up: atoms combine into molecules, molecules into organisms. Nothing depends on a level above it. All interactive atoms keep a 48 × 48 minimum hit area even when the visible shape is smaller. Type names are the five styles in Doc B §3.

## 4. Rules
1. **One card, one tap target.** A card is a single button. Two exceptions:
    1. The **Often Ordered card** is not a button. Only its plus button is interactive, and it never triggers anything else.
    2. The **order line** is a button (thumbnail, title, details) that contains one separate nested control, the quantity stepper. The stepper never triggers the line's edit action.
2. Decorative parts are hidden from assistive technology: chevrons, the plus between offer images.
3. **Yellow marks action and selection only** (Doc B 2.5). Of the components above, only these use yellow: Primary button, Plus button, Category pill (active), Category row (active), Checkbox row (checked), Barista's Way toggle (on), the order bar's count circle, and the empty-state button. Badges, chevrons and chips never use yellow.
4. No new component without a home. A new element needs an entry in this document, built only from values in Doc B.
5. Reuse before create. Size picker, Barista's Way and Add-on list are shared by the item sheet and the offer sheet. In an offer sheet each product has its own state for them, from the same hook.
6. No lines for separation beside the hamburger or above the order subtotal (Doc B 6.3).
